# DuskForge

DuskForge orchestrates real-time data processing and storage in a auto-scaling infrastructure through a RESTful API and data gateway.

DuskForge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/DuskForge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DuskForge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
